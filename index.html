About

Hi, I’m Bruno Garcia.

DevOps & Cloud Engineer

I’m a cloud and DevOps-focused software engineer with 12+ years of experience across backend development, cloud infrastructure and delivery automation.

Since February 2026, I’ve been a DevOps Engineer at Critical TechWorks, as part of the Orbit Core AWS team, helping manage the AWS cloud infrastructure supporting connected-vehicle services for BMW, MINI and Rolls-Royce. I work with Kubernetes and Terraform. I joined the company in October 2018, with an earlier software development role spanning automotive and electric-vehicle charging services.

My toolkit brings together AWS and Microsoft Azure, containerised services, serverless applications, Infrastructure as Code and CI/CD with GitHub Actions.

I enjoy turning complex problems into clear, practical solutions — with automation that helps teams deliver consistently.
